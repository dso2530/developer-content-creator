# Developer Content Creator

Developer Content Creator is an AI platform that automatically generates technical content from GitHub repositories.

## Features

- GitHub OAuth
- Repository analysis
- AI-powered content generation
- LinkedIn posts
- Facebook posts
- Blog articles
- Release notes
- Newsletter generation
- GitHub release summaries

## Architecture

- Java 21
- Spring Boot
- Maven Multi Modules
- Kafka
- PostgreSQL
- pgvector
- Ollama / OpenAI
- Kubernetes
- ArgoCD
